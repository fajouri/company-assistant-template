# Product scope
Private-deployment corporate policy assistant, one company per installation.
Audience: employees, HR content owners and technical administrators.
Planned: Entra single-tenant authentication; policy RAG with source versions; own leave balance and HR contact via read-only MCP; configurable branding/languages; accessible UI; audit and observability.
Excluded: HR decisions, medical data, arbitrary filesystem/SQL tools, write actions, multi-company SaaS.
Current delivery is an unauthenticated fictional interface shell only.
